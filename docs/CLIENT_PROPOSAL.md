## 1. Overview

This document outlines the website built for Art-Teas-Tree Café — what it
includes, how it works for you day to day, and a clear, one-time price with no
hidden or recurring charges.

The website is a custom-designed digital home for the café: a cinematic,

Crucially, the website is built so **you can keep it up to date yourself**, with
nothing more than a Google Sheet. No coding, no logins to learn, no developer

## 3. How you keep it updated

Everything that changes day to day — menu items, prices, events, photos — is
controlled from **one Google Sheet** that we set up for you.

1. You edit the Sheet (just like typing into a table).
2. You save it.
3. The website updates itself automatically.

There is **no admin panel to log into and no technical skill required**. If you
can use Google Sheets, you can run your website.

## 5. Why this cost

This is a **custom-built** website, not a template. Here is what the price
reflects — and why it represents strong value:

- **Bespoke design & build.** Every section is individually designed and coded
  to match the café's identity. Comparable custom café websites from agencies
  in India typically range from **₹40,000 to ₹1,00,000+**, often with mandatory
  annual maintenance fees on top.

- **A self-serve content system.** The Google-Sheets-powered menu and events
  setup means you are never dependent on a developer (and never paying one)
  for routine updates. This alone saves recurring costs that most businesses
  pay indefinitely.

- **The Events directory is a substantial piece of work.** The ₹5,000
  difference between the two packages covers genuinely more software: three
  distinct event page templates, photo galleries with a lightbox viewer,
  banner handling, registration links, an upcoming/past archive system, and
  the automatic Sheet-to-website pipeline behind it all.

- **One-time, honest pricing.** You pay once. You own the result. There is no
  subscription and no lock-in.
