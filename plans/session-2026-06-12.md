## 1. Hero Carousel — Drag/Swipe Scrollable

**Problem:** The hero was a pure cross-fade slideshow with no physical scroll gesture.

**What was done:**
- Replaced the `AnimatePresence` fade with an **Embla carousel** (already a project dependency, used by the events board).
- The strip is now drag/swipe-scrollable on desktop and touch-scroll on mobile.
- Auto-advance (6 s) pauses on hover and immediately on drag start (`pointerDown` event).
- Kept arrows, dot indicators, and added a playbill frame counter (`01 / 04`) with a handwritten `drag · টানুন →` hint.
- Gradient overlays and text column are `pointer-events-none` so the drag strip is grabbable anywhere; CTAs restore pointer events selectively.

## 6. Animations

All use `transform`/`opacity` only. All gated by `useReducedMotion()` or `prefers-reduced-motion`.

| Animation | Where | Detail |
|---|---|---|
| **Film-title letter reveal** | Hero h1 | Letters rise out of a clipped overflow line with 45 ms stagger; *Café* blurs in beneath (delay 1.15 s) |
| **Ken Burns drift** | Hero carousel | Active slide zooms 1 → 1.1 over 8 s, resets on slide change |
| **Scroll progress reel** | Fixed top strip | 2 px copper→crimson bar, `scaleX` driven by `useScroll().scrollYProgress` |
| **Projector flicker** | Reel viewfinder | ≤6% opacity wobble on a `mix-blend-overlay` layer over the scanlines |
| **Steam wisps** | Menu section heading | Three blurred rising wisps beside "What's steeping today" |
| **Bookshelf stagger** | Books section | Spines stagger up (4 ms per book) on scroll-into-view |
| **Book hover lift** | Books section | Spring-based 14 px vertical pull on hover |
| **Director's notebook hover** | Philosophy section | Tilted card straightens + lifts (spring, stiffness 220) on hover |

## 7. Mobile Optimisation

**Problems reported from a real device (390 px wide):**
- Hero photo almost entirely hidden by the heavy desktop-left gradient.
- "Where conversations steep slowly." caption not visible.
- Event-page nav stacked name + links in one cramped row, causing wrapping.
- EventHero banner too short — title block crashed into the rubber category stamp.
- Notice board was below the manifesto (wrong priority order).

**What was done:**

### CafeApp.jsx
- `min-h-screen` → `min-h-[100dvh]` so the mobile URL bar doesn't clip the hero.
- Mobile gets a top-to-bottom vignette (`from-top 55% → 12% → 94%`) instead of the heavy left-to-right; desktop keeps the original via `sm:` breakpoint.
- Hero photo opacity bumped to `80%` on mobile, `55%` on desktop.
- Tagline `text-[#F5F0E6]` (full cream, was 78% alpha) + `textShadow` for contrast over any photo.
- Bengali subtitle bumped 42% → 70% opacity, also gets the shadow.
- Scroll-nudge chevron hidden on mobile (`hidden sm:flex`) — swiping is the natural gesture.
- **Section order changed:** Hero → Ticker → **Events notice board** → Philosophy → Reel → Menu → Books. Events first.

### Nav.astro
- `flex-row` on desktop, `flex-col gap-2.5` on mobile (brand on top, links wrap below).
- Link list gets `-mx-1.5 flex-wrap` on mobile so pills don't overflow.
- Brand name is `whitespace-nowrap` to stop per-word stacking.

### EventHero.astro
- Aspect ratio: `aspect-[3/4]` on mobile, `aspect-[21/9]` on sm+. Taller poster gives the title block room.
- Category rubber stamp hidden on phones (`hidden sm:block`) — category is already named in the kicker.
- Title block horizontal padding tightened (`px-5 pb-7` → `sm:px-12 sm:pb-12`).
- "presents" rule line tracking/size tightened for narrow widths.
